How it works

Sender uploads a cover image and 2–5 secret images. The INN embeds all secrets invisibly into the cover. You receive a stego image (publicly sharable) and an encrypted key (private).

Receiver presents the stego image + key ID. The INN reverses the embedding and recovers all secrets at high fidelity.

Security model

✓ TLS 1.3 in transit
✓ AES-256-GCM key encryption at rest
✓ JWT + optional TOTP two-factor auth
✓ RBAC — sender / receiver / admin roles
✓ Per-IP rate limiting (10 ops/min)
✓ Immutable audit log on every operation
✓ Texture gate — rejects low-capacity covers
